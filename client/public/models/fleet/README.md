# Fleet viewing assets

Catalog of **boats, rafts, airships, mounts, and back-slot** meshes for the
`/fleet-assets` viewer.

| Folder | Role |
|--------|------|
| `boats/` | Play hulls (skiff…man o’ war) — drop GLBs here to preview locally |
| `rafts/` | Starter rafts / rowboats |
| `airships/` | Sky ships (CDN first) |
| `mounts/` | Toon RTS cavalry (CDN) |
| `back-slots/` | Cloak / quiver / pack |

**Do not git-dump R2 binaries.** Point `catalog.json` / `fleetAssetCatalog.ts` at
`/models/ships/…` or `https://assets.grudge-studio.com/…`.

SSOT: `shared/gameDefinitions/fleetAssetCatalog.ts`
Viewer: `/fleet-assets`
